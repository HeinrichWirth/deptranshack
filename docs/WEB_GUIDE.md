# Как пользоваться веб-демонстрацией

После запуска Docker откройте http://localhost:8870. У демонстрации два экрана: основная страница с расчётом и таблицей объектов и подробный просмотр одного сохранённого прогноза. Ни переключение кадров, ни движение виртуального поезда не запускают детектор повторно.

## Первый прогон

Ниже описана загрузка файла. При [запуске ROS 2](ROS2.md) файл в браузер загружать не нужно: страница выбирает текущий поток и обновляет срез и таблицу по мере расчёта. После остановки ROS-подписчика результаты доступны как сохранённый прогон. Подсветка точек конкретной группы появляется после итогового сохранения; во время расчёта видны попадания в габарит и измерения объектов.

1. Нажмите **«Выберите .db3»** или перетащите файл в область загрузки слева. Полоса показывает передачу файла в Docker, а не выполнение алгоритма.
2. После загрузки выберите **«Облако точек»** — топик PointCloud2. Если облако одно, менять ничего не нужно.
3. Нажмите **«Начать расчёт»**. Запись подаётся по её временным меткам. Можно оставить страницу открытой и наблюдать появление срезов.
4. Дождитесь **«Расчёт завершён»**. Ниже появится таблица объектов. Закрытие вкладки не останавливает сервер; результат можно снова выбрать в **«Сохранённых прогонах»**.

Одновременно выполняется один прогон. Для повторного расчёта загрузите файл ещё раз. Оригинал на компьютере не меняется. Чистая установка не содержит готовых облаков: сначала нужен ваш bag. Поддерживаемые поля и оси перечислены в [README](../README.md#подходящий-вход).

## Главный экран

| Элемент | Что он делает или показывает |
|---|---|
| Сохранённые прогоны | Открывает ранее загруженную запись и её результат |
| Состояние под кнопкой запуска | Различает подготовку, выполнение, завершение и ошибку |
| Исходный кадр | Номер пакета, для которого показан сохранённый результат |
| Расчёт алгоритма | Время работы алгоритма для выбранного результата, без загрузки файла и записи диагностики |
| Расчётов готово | Число завершённых циклов; оно меньше числа входных облаков |
| Следить за поездом | Во время расчёта автоматически показывает последний готовый результат |
| Срез в … м | Выбирает положение поперечного среза вдоль принятого пути; кнопки −1 м и +1 м двигают его на метр |
| ← Кадр / Кадр → и нижний ползунок | Переключают сохранённые расчёты. Ручное переключение выключает слежение |
| Проехать по прогнозу | Открывает подробный просмотр выбранного кадра в новой вкладке |
| Журнал расчёта | Открывает технический журнал, полезный при ошибке |

**Кадр и положение среза — разные вещи.** Переключение кадра меняет исходные наблюдения и прогноз. Изменение расстояния перемещает срез внутри одного прогноза. Чтобы спокойно рассмотреть место во время расчёта, снимите «Следить за поездом».

Серые точки — облако, зелёные — ходовые рельсы, жёлтые — контактный. Красным выделены попадания точек в проверяемый габарит. Рамка показывает поезд шириной 2,1 м и высотой 3 м от головок рельсов. Высота среза отсчитывается от рельсов, а не от положения лидара.

Подпись под срезом показывает число точек и попаданий в этом срезе. Это не число объектов во всей поездке. Для быстрого отображения главный экран может рисовать только часть точек; сам расчёт от этого не меняется.

Если написано **«Нет принятого прогноза в этом срезе»**, уменьшите расстояние или выберите другой кадр. Отсутствие принятого пути не означает отсутствие препятствия или свободный тоннель.

## Таблица объектов

По умолчанию видны только группы с обнаружениями минимум в двух разных исходных пакетах. Флажок **«Одиночные»** добавляет неподтверждённые группы для диагностики. Красная точка в одном срезе сама по себе не обязана стать строкой таблицы.

| Столбец | Как читать |
|---|---|
| Объект | Номер группы внутри этого прогона; номера разных запусков могут не совпадать |
| Кадры | Первый и последний кадры обнаружения. Не означает присутствие на каждом кадре между ними |
| Расстояние до объекта | Расстояние от лидара при первой детекции объекта |
| Ш × В | Оценка ширины и высоты видимой части по наиболее плотному наблюдению |
| Площадь | Ширина × высота этой видимой части; это площадь охватывающего прямоугольника, не площадь поверхности предмета |
| Посмотреть | Открывает характерный кадр объекта и выводит под таблицей ссылки на все кадры его обнаружения |

Близкие наблюдения объединяются **автоматически в пределах 10 м** в общей системе координат. Ручного выбора для объединения нет. Это намеренно грубое правило: два разных предмета рядом могут стать одной строкой. У каждой группы сохраняются исходные номера и наблюдения для разбора.

**CSV** выгружает таблицу, **JSON** — результат с подробностями. Подтверждение в двух пакетах означает повторяемость обнаружения, а не доказанную истинность препятствия: ложные объекты также могут повторяться.

## Подробный просмотр: виртуальный поезд

Откройте его кнопкой **«Проехать по прогнозу»** или через **«Посмотреть»** у объекта. Здесь облако выбранного расчёта неподвижно, а виртуальная рамка поезда движется по сохранённому пути.

| Управление | Назначение |
|---|---|
| Исходный кадр (с нуля) | Переход к указанному кадру; если расчёта на нём нет, выбирается ближайший следующий выполненный |
| Кнопки кадров и ползунок | Выбор другого сохранённого расчёта; положение поезда сбрасывается |
| ▶ Ехать / пауза | Автоматическое движение по пути текущего кадра |
| Скорость поезда | Только скорость анимации; не скорость вычисления и не измеренная скорость настоящего поезда |
| ◀ Шаг / Шаг ▶ | Движение на выбранный шаг; готовые кнопки задают 1, 2, 4 или 8 м |
| Толщина среза | Ширина участка облака вдоль пути, попадающего в поперечную проекцию. Большая толщина показывает больше точек |
| В начало | Возвращает к началу пути текущего кадра |
| Ползунок под срезом | Перемещает виртуальный поезд по сохранённому пути |
| Масштаб среза, колесо мыши | Приближение и отдаление изображения |
| Перетаскивание среза | Сдвиг изображения; «Сбросить вид» возвращает исходный вид |
| Показывать попадания красным | Включает и выключает красную подсветку, не изменяя расчёт |
| Путь сверху | Показывает изгиб пути; щелчок по нему перемещает поезд |

Движение заканчивается на конце принятого пути. Сохранённое продолжение учитывает защиту; его длина в просмотрщике не изменяется.

### Слои и цвета

- **Исходное облако** — реальные точки сохранённого пакета.
- **Опора STEP1** — ближние точки ходовых рельсов, найденные первым этапом.
- **Пара / опорная плоскость 1 и 2** — две линии принятого ходового пути, голубая и оранжевая.
- **Контактный · расчётная линия** — жёлтая линия контактного рельса.
- **Выбранный объект** — розовая подсветка объекта, открытого из таблицы.
- **Сравнение · белый** — диагностическая форма до защиты/коррекции, когда она сохранена. Это не второй принятый путь.
- **Расчётный центр** — вспомогательная линия середины пути.
- **Исходный слой 2 (нет в RAW)** — служебный слой старых размеченных данных; у сырой записи он пуст.

Выключение слоя лишь скрывает его. Проверка попаданий не перестаёт учитывать реальные точки из-за снятого флажка. Расчётные линии сами препятствиями не считаются.

Нажмите на точку среза, чтобы увидеть её дальность. Она измеряется **по прямой от лидара исходного кадра**. Это не оставшийся путь от нарисованной рамки виртуального поезда, поэтому значение не меняется при проезде по фиксированному облаку.

## Быстрый сценарий проверки

1. Дождитесь завершения прогона и нажмите «Посмотреть» у интересующего объекта.
2. Установите толщину среза 1 м и шаг 1 м. При необходимости приблизьте изображение.
3. Пройдите через объект кнопками шага, сопоставляя красные точки с рельсами и рамкой.
4. Вернитесь к таблице и откройте другой кадр того же объекта по ссылке под ней. Так можно проверить, что обнаружение повторяется.
5. Если форма пути вызывает сомнение, включите белое сравнение и контактную линию. Зафиксируйте номер кадра и положение среза: они позволяют повторить наблюдение.

При ошибке загрузки или расчёта сначала посмотрите сообщение на главной странице и [раздел диагностики](TROUBLESHOOTING.md). Описание самого метода находится в [ARCHITECTURE.md](ARCHITECTURE.md), история экспериментов — в [RESEARCH.md](RESEARCH.md).
