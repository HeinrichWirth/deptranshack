# Проверка версии 2026.10.23

Обновлены продолжение контактного профиля и выбор пути между последовательными расчётами. Код текущей ветки содержит эти исправления; прежние видео и отчёты не используются как проверка этой версии.

## Сборка и функциональные тесты

- Docker-образ собран из исходников: Python 3.12.14, GCC 12.2; все шесть native-модулей.
- Проверены контрольные суммы 416 исходных файлов движка.
- **21 из 21 теста прошли** внутри нового контейнера, включая десять регрессий для пустой полосы, восстановления по реальным точкам, запрета будущего облака, удержания согласованного хвоста, конфликта путей и возраста модели.
- `tests/full_http.py` загрузил в локальный веб-сервер фрагмент из первых **151 неизменённого сообщения** исходной записи. Получено 151 сообщение, завершено 22 расчёта, срез появился до окончания обработки, сохранена одна подтверждённая группа из двух исходных треков. Временная копия входа удалена штатно.

HTTP-проверка выполнена на фрагменте, а не на всей записи из 1510 сообщений. Полный прогон и ROS 2 DDS после обновления не перепроверены. Замеры скорости предыдущей версии здесь не повторяются.

## Демонстрация и последовательное сравнение

Демонстрация в `presentation/` построена по сохранённому **Windows / Python 3.14 / MSVC** расчёту обновлённого алгоритма. На непересекающихся трёхкадровых пакетах первое обнаружение большого объекта - 96,956 м, подтверждение через 0,30 с - 96,487 м. Восстановленный путь при первом обнаружении - 109,327 м. Во входе нет будущих облаков или меток препятствия.

Это измерения конкретного офлайн-прогона. Анимация включает и пакеты без обнаружения; скорость воспроизведения не является производительностью алгоритма. Подробное сравнение с прежней политикой: [ALGORITHM_UPDATE.md](ALGORITHM_UPDATE.md).

## Сравнение Windows и Linux

Дополнительно проверены одинаковые причинные входы кадров 12, 15, 131 и 794. Использованы одни исходные сообщения и сохранённые позы; сравнивались рельсы, контактная линия, опоры и индексы поддержки.

**Численная эквивалентность сборок не подтверждена.** На кадре 15 индексы и состояния совпали, геометрия отличается примерно на 2,4·10⁻⁸ м. На кадрах 12 и 131 различается также выбранная поддержка: это уже изменение ветви поиска, а не только округление координат. На кадре 794 геометрия отличается менее чем на 10⁻⁶ м, но набор поддержки тоже не идентичен. Причина расхождений между окружениями пока не локализована.

Поэтому Windows-демонстрация не объявляется побитовым эталоном Docker-выхода, а точные дальности не обещаются при произвольной пересборке. Функциональная проверка Docker прошла отдельно. Исходники и условия сравнения доступны в `tests/compare_causal_build.py`; машинный отчёт сохраняет неуспешные сравнения, без замены их успешным статусом.
