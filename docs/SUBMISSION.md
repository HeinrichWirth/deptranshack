Видео показывает работу просмотрщика на сохранённом результате полного прогона: таблицу групп, исходные кадры и проезд по прогнозу. Это запись разбора результата, а не демонстрация живой подписки DDS. Для повторения расчёта используется сценарий ниже.

## Сценарий демонстрации

1. Клонировать репозиторий и выполнить `docker compose up --build -d`.
2. Открыть http://localhost:8870 и загрузить распакованный DB3.
3. Выбрать топик PointCloud2 и нажать «Начать расчёт».
4. Наблюдать поступление результатов в поперечном срезе.
5. После завершения открыть группу в таблице, проверить кадры и дальность, проехать по сохранённому пути.

На упаковочном прогоне получены 1510 сообщений и завершены 390 расчётов. Первое наблюдение группы 1 — кадр 131, дальность 70,63 м от лидара. Это один проверенный пример, не максимальная гарантированная дальность. Номера относятся к сохранённому прогону и могут меняться при повторении.

## Соответствие техническому заданию

| Требование | Состояние MVP | Проверка или следующий шаг |
|---|---|---|
| Запуск в Docker без ручной установки зависимостей | Реализовано | Dockerfile, Compose, проверка сборки |
| Чтение ROS 2 bag | Реализовано для одного DB3, CDR1 PointCloud2 | Загрузка через веб, выбор топика |
| Обработка потока | Реализовано как воспроизведение временных меток записи | Кольцевой буфер и ограниченные каналы |
| Подключение к ROS 2 Humble | Реализовано | PointCloud2 через DDS, результат в ROS-топике; [запуск](ROS2.md) |
| Ubuntu 22.04 и ROS 2 Humble внутри среды | ROS-адаптер в образе Humble/Jammy | Геометрия остаётся в отдельном прежнем Python 3.12 образе |
| Результат обнаружения и расстояние | Реализовано | Группы, исходные кадры, дальность, CSV/JSON |
| Визуализация входа и результата | Реализовано | Веб-срез, рельсы, габарит, красные попадания |
| Короткое видео | Приложено | Просмотр сохранённого результата |
| `ros2 bag play` и живая демонстрация ROS 2 | Проверено локально на полной записи | [Отчёт DDS](ROS2_VALIDATION.md), [видео](../presentation/HW_ROS2_live.webm) |
| Стенд Intel i7-9700E, Ubuntu 22.04.5 | Не проверено | Замеры выполнены на стенде разработки |
| Неизвестный контрольный bag | Не проверено | Испытание на стороне заказчика |

Для стенда используется отдельный [ROS 2 запуск](ROS2.md), для загрузки файла через браузер остаётся прежний режим. Результаты локального DDS-теста не являются замером на оборудовании заказчика.
