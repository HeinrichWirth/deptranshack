# Демонстрация текущего алгоритма

[MP4](corrected_detection.mp4) · [GIF](corrected_detection.gif)

Запись с синтетическим большим препятствием, последовательные результаты обновлённого алгоритма в Windows / Python 3.14 / MSVC. Слева показаны исходное облако и принятые рельсы в двух проекциях. Справа - поперечное сечение у выделенных компонентов. Красным отмечены реальные индексы обнаруженных точек из сохранённых пакетов.

Первое обнаружение: 96,96 м; подтверждение новым пакетом через 0,30 с: 96,49 м. К концу показанного участка объект находится примерно в 61,60 м. Пакеты без обнаружения также показаны. На первом обнаружении и подтверждении воспроизведение приостановлено для чтения; исходное время остаётся на экране.

Это визуализация сохранённого последовательного расчёта, а не видеозапись живого ROS 2 потока и не замер производительности. Для обзора исходное облако прорежено только при рисовании; расчёт и выделенные точки не менялись. В ролике нет интерполяции детекций или дорисованных попаданий.

Полный расчёт новой записи: [инструкция запуска](../README.md). Проверки: [отчёт](../docs/RELEASE_VALIDATION.md).
