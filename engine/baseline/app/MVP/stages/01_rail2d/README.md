# Этап 01 — поиск рельсов Rail2D

Снимок принятого этапа от 26 сентября 2026 года. Основа для дальнейшей сборки
MVP. Все существовавшие файлы скопированы без изменения содержимого.

## Содержимое

- `src/rail2d_head_v2.py` — актуальный выбор двух поддержанных верхних головок.
- `src/rail2d_motion_v2.py` — направление по первой допустимой будущей позе,
  удалённой от T минимум на 50 см.
- `src/rail2d_detector.py` — необходимые базовые операции: базис, плотность,
  кандидаты; также содержит исходный детектор для сравнения.
- `src/rail2d_gt_geometry.py` — отдельная проверка расчётного GT, только для оценки.
- `config/detector_v2.json` — точные параметры принятого детектора.
- `config/gt_check_protocol.json` — правило расстояния между GT-центрами
  1,48–1,62 м включительно с учётом разности высот.
- `experiment_snapshot/` — точные копии всех скриптов Rail2D, проверок,
  генераторов отчётов и трёх документов этого эксперимента.
- `reference/` — итоговые метрики, подтверждение полного повторного прогона,
  проверки артефактов и синтетических сценариев.
- `MANIFEST.json` — SHA-256 каждого сохранённого файла и путь оригинала.

## Подключение модулей при сборке MVP

Модули `src/` не зависят от исходной папки проекта, LAS, карты или просмотрщика.
Для них нужны Python 3.12+ и пакеты из `requirements.txt`. Зафиксированы версии,
использованные в проверенном окружении. Добавьте `src/` в путь импорта приложения.
Загружайте именно `config/detector_v2.json`: значения DEFAULT в базовом модуле
относятся к исходному эксперименту, а не к выбранной конфигурации v2.

```python
import json
from pathlib import Path
from rail2d_head_v2 import detect

stage = Path('/path/to/01_rail2d')
config = json.loads((stage / 'config/detector_v2.json').read_text(encoding='utf8'))
result = detect(points_vw, config)  # N x 2, метры; только точки текущего T
if result['status'] == 'ok':
    rail_centres_vw = result['pair']  # 2 x 2: сначала меньшее v, затем большее
else:
    refusal_reason = result['reason']
```

`MotionSelector(metadata).select(i)` возвращает базис и сведения об ожидании.
Каждая запись metadata содержит `lidar_pose_in_folder` (4 x 4),
`header_time_ns`, `pose_status`, `pose_uses_future`. Позиции и позы — оценки.
Базис имеет столбцы `(forward, lateral, up)` в системе LiDAR T.
Из текущего облака XYZ выбираются точки с `0 <= XYZ @ forward <= 8`;
в детектор передаются только `XYZ @ basis[:, 1:]` выбранных точек.
Для зарегистрированного LAS сначала применяется `(xyz_map - t_T) @ R_T`.

При отказе поле `pair` иногда содержит отвергнутого кандидата для диагностики:
принимать результат нужно только по `status == 'ok'`. Confidence — эвристическая
оценка, а не вероятность правильности. L/R — меньший/больший v, не обещание
соответствия физической левой/правой стороне транспортного средства.

Только облако T участвует в детекции. Будущие позы используются до первого
прямого смещения 50 см, без будущих облаков, накопления дрожания и перехода
через разрывы. На остановках есть ожидание (в проверке до 44,30 с), а при
недостаточном движении — отказ. Временного фильтра результатов пока нет.
GT, классы и оценочная карта не должны поступать в предиктор MVP.

## Состояние проверки

6 551 кадр / 11 записей, четыре варианта заново рассчитаны. Полный v2:
6 351 принятая пара, 200 отказов. После проверки GT оценена 5 971 пара;
